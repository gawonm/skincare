# NIA Case 평가 데이터

이 폴더에는 NIA Case 검색·리랭킹 평가에서 사용하는 JSONL만 둔다.
테스트 코드와 평가 실행기는 상위 `tests/agent/`에 유지한다.

## 파일 유형

- `*_queries_*`, `*_golden_*`: 평가 질의와 확정 골든셋
- `*_judgments_*`, `*_adjudications_*`: 블라인드 판정과 보완 판정
- `*_pool_*`, `*_probe_*`: 후보 풀과 재현용 검색·리랭크 결과
- `*_results_*`, `*_summary_*`: 단계별 평가 결과와 최종 요약
- `*_blind_*`, `*_manifest_*`: 판정 편향을 줄이기 위한 블라인드 입력과 내부 매핑

후보 풀과 블라인드 파일은 크기가 크더라도 최종 qrel의 생성 근거이므로 임의로 삭제하지 않는다.
새 평가 산출물도 이 폴더에 저장하고, Python 코드에서는 저장소 루트 기준 경로를 사용한다.
