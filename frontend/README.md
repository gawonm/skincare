# frontend

아직 스택을 정하지 않았다. 폴더만 잡아 둔 상태다.

## 정해야 할 것

| 항목 | 후보 | 판단 기준 |
| --- | --- | --- |
| 프레임워크 | Next.js / React + Vite / Streamlit | 파이썬만 쓸 거면 Streamlit, 일반 사용자용 웹이면 Next.js |
| 통신 방식 | 일반 요청 / 스트리밍(SSE) | LLM 답변을 한 글자씩 보여줄지 여부 |

## 백엔드 주소

로컬 개발 기준으로 백엔드는 `http://localhost:8000` 이다.
API 문서는 `http://localhost:8000/docs` 에서 볼 수 있다.
