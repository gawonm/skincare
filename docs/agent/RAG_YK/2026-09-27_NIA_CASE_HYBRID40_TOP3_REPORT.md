# NIA Case Dense40 대 Hybrid40 동일 후보 수 비교

## 실험 조건

- 24개 기존 개발·회귀 질의의 원문과 NIA 사례 3,581건을 사용했다.
- Dense40은 BGE-M3 후보 40건, Hybrid40은 Dense 상위 36건과 그 36건에 없는 NIA 질문 필드 BM25 후보 4건이다. BM25 후보가 원래 Dense 37~40위와 겹칠 수 있다.
- 두 조건 모두 같은 `BAAI/bge-reranker-v2-m3`와 빈 `CareContext`를 적용했다. 관리 필터의 효과는 포함하지 않는다.
- 기존 Dense40 재정렬 결과를 재사용하고 Hybrid40만 이번에 실행했다. 시간 수치는 서로 다른 실행의 관측값이다.
- 기존 qrel에 없던 Top-3 사례 중 3건은 이번 Codex 세션이 판정했고, 3건은 앞선 Codex 판정을 재사용했다. 변경된 순위를 확인한 뒤 판정했으므로 완전 블라인드 평가가 아니다.

## 해석 범위

- 복합 여드름·따가움 질의에서 Hybrid가 올린 사례는 상태의 일부만 맞아 nDCG@3 손실이 컸다. 미백 제품 사용 후 자극 질의에서는 현재 자극 관리와 충돌하는 사례가 상위로 올라왔다.
- qrel Recall은 판정 풀 안의 관련 사례만 분모로 계산한다. 전체 코퍼스의 완전 Recall이 아니다.
- 이 24건은 반복 사용한 개발·회귀셋이다. 별도 복합 질의 12건 확인 전에는 운영 일반화 성능이나 관리 방향 개선으로 주장하지 않는다.
- 이번 실행은 저장된 후보 목록을 재사용했으므로 BM25 조회·인덱스 구축 및 실제 DB 요청 시간을 포함한 종단 지연은 측정하지 않았다.
- 후속 [Top-5 포함률 비교](2026-09-27_NIA_CASE_TOP5_INCLUSION_REPORT.md)에서는 세 방식의 Hit@5와 등급 3 Hit@5가 같았다. 이 워크플로우의 주목적인 관련 사례 포함 여부는 해당 보고서의 Hit·관련 사례 수 지표로 읽는다.
