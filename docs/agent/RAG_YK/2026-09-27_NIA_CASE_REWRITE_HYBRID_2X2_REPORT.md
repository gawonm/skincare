# NIA Case 질의 재작성 × Dense/Hybrid 2×2 비교

## 평가 조건

- 질의: 기존 코퍼스 상대 개발·회귀셋 24건
- 재작성 모델: `gpt-4o-mini`
- 실제 문장이 바뀐 질의: 23/24
- Dense: BGE-M3 Top-40
- Hybrid: BGE-M3 Top-40과 BM25 Top-40을 RRF로 합쳐 Top-40
- 이번 실행: Top-40 후보 회수 비교만 완료, 공통 BGE reranker는 미실행
- BM25는 NIA 질문·답변의 한국어 단어와 2글자 부분 토큰을 사용

## 결과

| 질의 | 검색 | qrel Recall@40 | Success@40 | 검색 초 |
| --- | --- | ---: | ---: | ---: |
| original | dense | 0.648 | 0.917 | 0.081 |
| original | hybrid | 0.685 | 0.917 | 0.092 |
| rewritten | dense | 0.617 | 0.917 | 0.079 |
| rewritten | hybrid | 0.648 | 0.917 | 0.090 |

## 질의별 쌍대 비교

| 비교 | 개선 | 하락 | 동일 |
| --- | ---: | ---: | ---: |
| `original_hybrid_vs_dense` | 10 | 5 | 9 |
| `dense_rewritten_vs_original` | 2 | 4 | 18 |
| `hybrid_rewritten_vs_original` | 6 | 10 | 8 |

## 1차 판단

- 원문 Hybrid는 원문 Dense보다 qrel Recall@40이 0.648에서 0.685으로 높았다. 질의별 하락도 있으므로 공통 리랭커 결과를 보기 전에는 운영 채택하지 않는다.
- 재작성은 Dense에서 0.648→0.617, Hybrid에서 0.685→0.648이었다. 현재 프롬프트의 운영 채택 근거는 없다.
- 재작성 API 평균 지연은 0.964초였다.

## 해석 제한

- qrel Recall@40은 현재 골든 파일에 판정된 관련 Case만 분모로 사용하며 전체 코퍼스 recall이 아니다.
- 검색 시간은 질의 임베딩 계산을 제외한 DB Dense 조회와 메모리 BM25·융합 시간이다. 재작성 API 시간은 별도로 집계했다.
- 리랭커 미실행 시 P@3·nDCG@3·Hit@3은 `미정`이며 방법 선택의 최종 수치가 아니다.
- 새 방법이 Top-3에 올린 미판정 Case가 있으면 해당 조건의 P@3·nDCG@3는 판정 완료 질의만 집계한다.
- 이 24건은 검색과 필터 개발에 반복 사용한 개발·회귀셋이므로 독립 일반화 성능으로 해석하지 않는다.
- 재작성 효과와 검색 방식 효과는 각각 같은 축의 두 조건을 비교하며, 두 변경을 한 번에 원인으로 해석하지 않는다.
