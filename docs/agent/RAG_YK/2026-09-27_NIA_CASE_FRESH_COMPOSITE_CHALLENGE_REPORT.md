# NIA Case RAG 새 복합 질의 12건 점검

## 목적과 평가 조건

앞선 24건에서 관리 필터 뒤 Case 결과가 비거나 현재 피부 상태와 맞지 않는 조언이 남았다.
정확히 같은 질의를 다시 고르지 않고 [복합 질의 12건](../../../tests/agent/nia_case_eval_data/nia_case_fresh_composite_queries_20260927_v1.jsonl)을 검색 실행 전에 고정했다.
9건은 현재 자극·회복 우선, 3건은 자극이 없다고 명시한 대조 질의다.
각 CareContext는 질의의 인용 구절에 근거한 Codex 판정이며 OpenAI 예측이 아니다.
12건은 서로 다르고 기존 의미 평가 질의와 정확히 일치하는 문장은 0건이다.

실제 로컬 DB의 `nia_case_text/v1`에서 동일 질의로 Dense Top-40을 조회하고,
동일 BGE reranker 점수를 필터 전후에 사용했다. 제품·Evidence RAG는 평가하지 않았다.
이 질의는 앞선 오류 유형을 보고 설계한 **합성 도전셋**이다. 실제 사용자 분포의 독립 표본이나
임상 전문가 판정으로 해석하지 않는다.

## 관련성·관리 방향 판정 결과

필터 전후 Top-3 합집합 **49개 후보**를 Codex가 원문 질문·답변을 읽고 판정했다.
[질의별 판정](../../../tests/agent/nia_case_eval_data/nia_case_fresh_composite_judgments_20260927_v1.jsonl)은
관련성 `0~3`과 현재 요청의 관리 방향 `aligned/conflict`를 별도로 보존한다.
관련성 2는 주 고민이 맞지만 복합 조건의 일부를 놓친 경우, 3은 복합 고민과
부위·상태가 모두 직접 맞는 경우로 판정했다. 답변의 관리 권고는 별도 방향 축으로
판정했다. 판정 누락은 0건이다.
`conflict`는 현재 자극을 먼저 안정시키려는 요청에 각질 관리·새 활성 성분·제품 추가를
앞세우거나, 따갑다고 한 제품 사용을 그대로 반복 권한 경우다. 의료 안전성의 확정
판정이 아니라 **질의와 사례의 관리 방향 충돌**이다.

| 항목 | 필터 전 | 현재 필터 |
| --- | ---: | ---: |
| Case 결과가 있는 질의 | 12/12 | 10/12 |
| 관련 Case Hit@3 (등급 2 이상) | 12/12 | 10/12 |
| 복합 요청 직접 일치 Hit@3 (등급 3) | 1/12 | 1/12 |
| Precision@3 (관련 슬롯 / 36) | 33/36 = 0.917 | 28/36 = 0.778 |
| 판정 합집합 기준 nDCG@3 | 0.955 | 0.794 |
| 관리 방향 충돌 노출 슬롯 | 27 | 21 |
| 관리 방향 부합 노출 슬롯 | 9 | 9 |
| Top-3 구성이 바뀐 질의 | 기준 | 9/12 |

빈 결과도 Precision@3 분모에 3칸으로 포함했다. nDCG의 이상적 순위는 질의별로
**이번에 판정한 후보 합집합**에서만 만들었으므로 전체 코퍼스 nDCG가 아니다.
[집계 원본](../../../tests/agent/nia_case_eval_data/nia_case_fresh_composite_scored_summary_20260927_v1.jsonl)을 보존했다.
충돌 노출 6칸 감소는 빈 결과 2개 질의에서 각각 3칸씩 보류한 수와 같다.
관리 방향에 부합하는 슬롯은 늘지 않았다. 이를 전체 조언 안전성 향상이나
검색기 자체의 관련성 향상으로 해석하지 않는다.

두 빈 결과 질의 `fresh_composite_01`, `fresh_composite_02`는 각각 Dense Top-40
**40건 모두** 현재 필터에서 제외됐다. `fresh_composite_11`은 40건 중 3건만 남았다.
[질의별 후보·점수·원문](../../../tests/agent/nia_case_eval_data/nia_case_fresh_composite_results_20260927_v1.jsonl)과
[집계](../../../tests/agent/nia_case_eval_data/nia_case_fresh_composite_summary_20260927_v1.jsonl)를 보존했다.

Top-3 원문을 읽어 확인한 추가 문제는 다음과 같다.

| 질의 | 현재 출력에서 확인한 문제 |
| --- | --- |
| `03` | 새 세럼 뒤 따갑고 벗겨진다고 했지만, 턱 여드름을 위한 성분·제품 추가 사례가 올라온다. |
| `04` | 자외선 차단제를 바를 때 따갑다는 요청에 차단제 사용을 반복 권하는 사례와 비타민 C 세럼 사례가 올라온다. |
| `07` | 레티놀 사용 뒤 붉고 화끈거리는데, 주름 성분을 계속 추가하는 사례가 올라온다. |
| `08` | 면도 뒤 따가운데, 대체된 건조 사례까지 저자극·정기적 각질 관리를 권한다. |
| `09` | 크림이 따갑고 진정과 피지 관리의 우선순위를 물었지만, 여드름용 세럼·각질 관리 사례가 올라온다. |
| `10` | 미백 제품을 더하기 전에 현재 붉고 당기는 볼을 어떻게 관리할지 물었지만, 미백 세럼 추가 사례가 올라온다. |
| `12` | 자극이 없는 모공·기미 복합 질의인데, Top-3는 모두 모공 사례다. |

이는 **표현 필터를 통과했다는 사실만으로 현재 조언 적합성을 보장할 수 없고**,
관련성 점수가 높아도 회복 우선 의도나 복합 고민 한 축을 놓칠 수 있음을 보여준다.
49건의 판정은 질의 제작·후보 확인과 같은 과정에서 이뤄진 단일 Codex 판정이다.
블라인드 다중 판정이나 전문가 합의가 없고 합성 도전셋이므로 발표에서는 개발 진단
수치로만 사용한다.

## 빈 결과 재검색 탐색

빈 결과 2건에만 [별도 대안 질의](../../../tests/agent/nia_case_eval_data/nia_case_fresh_rescue_queries_20260927_v1.jsonl)를
사후 구성해 로컬 DB에서 다시 검색하고 원래 사용자 질의로 BGE 재정렬했다.
두 질의 모두 Case Top-3가 생겼다. [결과 원문](../../../tests/agent/nia_case_eval_data/nia_case_fresh_rescue_results_20260927_v1.jsonl)을 보존했다.

그러나 `01`의 재검색 1위는 붉고 따가운 볼에 대한 안정화보다 모공 관리 제품과
`꾸준한 각질 관리`를 권한다. `02`의 재검색 2위는 볼이 화끈거리는 상태에서도
`정기적인 순한 각질 케어`를 제안한다. 두 표현은 현재 필터를 통과한다.
재검색은 빈 결과를 채웠지만 현재 조언 적합성을 검증하지 못했으므로 **운영에 연결하지 않았다**.
Dense Top-40을 무조건 Top-100으로 늘리는 방식도 앞선 복합 질의에서 필터 통과 후보가
1건뿐이고 그 답변에 각질 제거 성분 제안이 있어 근거가 부족하다.

## 프로젝트 방향에 따른 다음 게이트

Case는 답변 생성과 Claim 추출의 앞단이므로, 출력 수만 높이기 위해 현재 상태와
충돌하는 사례를 반환해서는 안 된다. 현재 구현은 명시적 고강도 관리 권고를 일부
막지만, **새 제품 추가 시점·부위·회복 우선순위**를 일관되게 구분하지 못한다.

1. 판정한 49건의 `aligned/conflict` 근거를 후보별 인용 구절과 함께 재검토하고,
   애매한 사례는 독립 판정으로 확인한다.
2. 재검색 후보는 출력 유무 외에 관련성·현재 조언 적합성을 모두 통과해야 채택한다.
   대안 질의를 전체 질의에 상시 적용한 과거 실험에서는 관련 Case 회수율이 하락했다.
3. 발표 수치에는 개발 24건과 이번 합성 도전 12건을 분리하고, 실제 사용자 분포를
   대표하는 독립 표본이나 의료 안전성 향상으로 표기하지 않는다.

이번에는 Agent 평가 코드와 문서만 추가했다. 운영 Case·Product·Evidence 경로,
DB 스키마, 공용 설정은 바꾸지 않았다.
로컬 DB·BGE 본 평가 12건과 재검색 2건을 완료했고, Agent 테스트 356개와 Ruff 검사를 통과했다.
이번 후속 평가에는 OpenAI API를 호출하지 않았다.
