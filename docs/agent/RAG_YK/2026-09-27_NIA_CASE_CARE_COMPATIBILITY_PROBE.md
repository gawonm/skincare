# NIA Case 피부 상태-관리 부적합 안전 브레이크 집중 점검

## 목적

- 화끈거림·따가움·붉어짐과 안정화·장벽 회복을 함께 요청한 질의만 대상으로 한다.
- 해당 상태에서 BHA·레티놀·반복 각질 제거·강한 세안을 권하는 답변은 제외한다.
- 적합한 Case가 남지 않으면 위험 답변으로 Top-3를 채우지 않고 Case 결과를 보류한다.
- Dense Top-40과 BGE 점수 계산 방식은 유지하고 하이브리드 검색은 사용하지 않는다.

## 집중 점검 결과

- 질의: 2건
- 기존 피부 상태-관리 부적합 노출: 4건
- 변경 후 기존 판정 기준으로 확인된 부적합 노출: 0건
- 변경 후 신규 판정 필요 후보: 0건

| 질의 | 이전 Top-3 등급 | 이후 Top-3 등급 | 이전 부적합 | 이후 확인 부적합 | 신규 판정 |
| --- | --- | --- | ---: | ---: | ---: |
| `evaluation_core_pores_08` | 0,0,0 | 결과 없음 | 3 | 0 | 0 |
| `evaluation_rare_sensitive_01` | 2,2,0 | 2,2,2 | 1 | 0 | 0 |

## 해석 제한

신규 노출 후보의 보완 판정까지 완료했다. 이 결과는 문제 유형 2건에 대한 집중 점검이므로 전체 24개 질의의 성능 변화는 별도 회귀 평가로 확인한다.

## 업데이트의 의미

- 이번 변경은 임베딩 검색이나 BGE 점수 자체의 성능 개선이 아니라, 리랭킹 이후 적용하는 **안전 제약**이다.
- `evaluation_rare_sensitive_01`은 부적합 후보를 제외한 뒤 기존 Top-40 안의 관련 후보가 올라왔다. 이는 후보 풀에 적합 사례가 있으면 안전성과 관련성을 함께 개선할 수 있음을 보여준다.
- `evaluation_core_pores_08`은 Top-40 안에 안전한 관련 후보가 없어 결과를 보류했다. 이는 리랭커만의 문제가 아니라 현재 코퍼스 또는 후보 풀의 **안전한 사례 커버리지 부족**을 드러낸다.
- 결과 보류는 잘못된 Case를 제공하는 것보다 안전하지만, Case 출력률과 일반 검색 지표는 낮출 수 있다. 따라서 부적합 노출 수만으로 최종 성능을 판단하지 않는다.
- 규칙은 활성 자극 신호와 회복 우선 의도가 동시에 있는 좁은 상황에만 작동한다. 일반적인 BHA 질의와 자극 관리를 피하라는 Case는 유지한다.

## 다음 검증 기준

전체 24개 질의 회귀 평가에서는 `nDCG@3`, `Precision@3`, `Hit Rate@3`, `Grade-3 Hit Rate@3`과 함께 다음 값을 확인한다.

- `Case Output Rate`: 질의별로 Case가 한 건 이상 반환된 비율
- 피부 상태-관리 부적합 노출 수: 안전 필터가 막아야 하는 Case가 최종 결과에 남은 수
- 안전 보류 질의 수: 필터 적용 후 반환할 Case가 없어진 질의 수

Top-3가 항상 세 건이라는 전제가 깨졌으므로, 관련성 지표와 출력률을 분리해 보고해야 안전성 향상을 검색 성능 향상으로 잘못 해석하지 않는다.
