# NIA Case Dense40 대 Hybrid48 BGE Top-3 최종 비교

## 평가 조건

- 질의: 기존 개발·회귀셋 24건의 원문
- 공통 reranker: `BAAI/bge-reranker-v2-m3`
- Dense40: 기존 BGE-M3 후보 40건
- Hybrid48: Dense40 전체와 질문 전용 BM25 신규 후보 8건
- 기존 qrel에 없던 Hybrid Top-3 후보 4건은 현재 Codex 세션이 동일한 0~3 기준으로 보완 판정했으며 외부 API에는 전송하지 않음

## 해석

- Hybrid48은 후보 Recall@40을 높였지만 공통 BGE reranker 뒤 Top-3 평균 품질의 우위는 확인되지 않았다.
- 후보가 40건에서 48건으로 20% 늘면서 이 실행의 평균 rerank 시간도 증가했다.
- 추가 4건은 기존 qrel과 평가자가 다르며, 24건도 반복 사용한 개발·회귀셋이므로 일반화 성능으로 제시하지 않는다.
- 현재 자료에서는 Dense40을 기본안으로 유지하고, Hybrid48은 독립 평가셋에서 이득이 재현될 때 채택하는 편이 타당하다.
